EventBook – Event Booking System

EventBook is a full-stack web application that allows users to explore events, book tickets, and manage their bookings. It also provides an admin dashboard to manage events and monitor bookings.

Features

User Features

User registration and login

Secure authentication using JWT

Browse available events

Book event tickets

View booking details in My Bookings

Responsive and user-friendly interface

Admin Features

Admin dashboard

Create and manage events

View and manage bookings

Manage event information
